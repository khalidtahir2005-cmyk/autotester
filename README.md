🚀 AutoTester Pro v3.0
AutoTester Pro est une application de bureau intuitive et moderne conçue pour automatiser l'exécution de vos tests Python (pytest). Développée avec PyQt6, elle offre une expérience utilisateur fluide pour les développeurs souhaitant gagner en productivité.

✨ Fonctionnalités
Drag & Drop Intelligent : Glissez-déposez vos dossiers de projet ou fichiers de tests directement dans l'application.

Interface Moderne : Design "SaaS-ready" avec un thème sombre, des dégradés élégants et des animations fluides.

Multithreading : Exécution des tests en arrière-plan sans bloquer l'interface graphique.

Console en Temps Réel : Visualisez les logs et résultats de vos tests directement dans une console stylisée.

Feedback Visuel : Barre de progression et indicateurs de succès/échec (Vert/Rouge) pour un suivi instantané.

🛠️ Technologies utilisées
Langage : Python 3.14

Framework GUI : PyQt6

Outil de test : Pytest

Design : QSS (Qt Style Sheets)

🚀 Comment l'utiliser ?
Prérequis : Assurez-vous d'avoir Python installé et pytest configuré dans votre environnement.

Installation :

Bash
pip install PyQt6 pytest
Lancement :

Bash
python autotester.py
Utilisation : Sélectionnez votre dossier de projet ou fichier .py, cliquez sur "Run Tests", et consultez les résultats dans la console intégrée.
